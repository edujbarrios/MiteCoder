# Capability roadmap

- **v0.1:** single-model CPU agent, strict tools, raw resource metrics, reproducible inference,
  and MicroSWE framework.
- **v0.2:** measured CPU/RAM baselines, retrieval ablations, and more language symbol extractors.
- **v0.3:** controlled Q2/Q3/Q4/Q5 quantization experiments with equal task and compute budgets.
- **v0.4:** resumable verified downloads, additional model families, and ARM measurements.
- **v0.5:** run history, benchmark comparison views, and richer local editor workflows.
- **v0.6:** tiny-router and specialist-coder experiments under matched resource budgets.
- **v1.0:** stable offline agent, benchmark protocol, and extension interfaces.

Good first issues include another language symbol extractor, an original MicroSWE task, lexical
ranking improvements, ARM metadata, CLI reporting, metrics exporters, and documentation.
